#	Техническое Задание

##	Введение
Документ создается для предоставления доказательств деятельности на проверке на учебной практике, а также для дальнейшего написания документации и удобной разработки необходимого для выполнения практики ПО

##	Цель
Готовая программа должна считывать вводимые данные квадратной матрицы из консоли или из текстового документа, и выводить вычисленную сумму элементов главной и побочной диагоналей.

##	Объект и требования
- Способность считывать данные из файла
- Точное вычисление требуемого результата
- Устойчивость к ошибкам ввода данных
- Понятный оконный UI (с помощью Tkinter)
- Модульность (графический, функциональный, главный)
