# Educational-practice-2026
19.10.2026 - 31.10.2026 ИСП-31с  ПМ.06 "Сопровождение ИС"

## Описание

Консольная программа на языке Python с возможностью ввода и вывода данных через файл или консоль для нахождения суммы элементов главной и побочной диагоналей квадратной матрицы, которую вводит пользователь.

[![Build Status](https://github.com/Sn0w-t3a/Educational-practice-2026/actions/workflows/ci.yml/badge.svg)](https://github.com/Sn0w-t3a/Educational-practice-2026/actions/workflows/ci.yml)

## Возможности
- Ввод/вывод через файл
- Ввод/вывод через консоль
- Вычисление суммы главной и побочной диагоналей матрицы
