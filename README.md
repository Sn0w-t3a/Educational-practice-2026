## Описание

Консольная информационная система на языке Python для нахождения **суммы элементов главной и побочной диагоналей квадратной матрицы**, сгенерированной по параметрам пользователя. Поддерживает ввод и вывод данных как через консоль, так и через файл.

Проект сопровождается полным комплектом технической документации, модулем логирования, модулем резервного копирования шаблонов генерации матриц и набором тест-кейсов, подтверждающих соответствие ключевых модулей техническому заданию.

## Возможности

- **Ввод матрицы:**
  - с клавиатуры — по одному числу на строку;
  - с клавиатуры — строка = `n` чисел через пробел или запятую;
  - из текстового файла — числа через пробел/запятую, необязательная первая строка с порядком `n`.
- **Расчёт:**
  - сумма элементов главной диагонали `Σ m[i][i]`;
  - сумма элементов побочной диагонали `Σ m[i][n−1−i]`.
- **Вывод:**
  - в консоль — с выравниванием столбцов;
  - в текстовый файл — числа через пробел, одна строка = одна строка матрицы.
- **Логирование:**
  - консоль — `INFO`+ (лаконично);
  - файл `logs/app.log` — `DEBUG`+ (полная история, включая дампы матриц).
- **Резервное копирование шаблонов:**
  - ZIP-архивы с меткой времени;
  - контроль целостности по SHA-256;
  - журнал `backups/manifest.json`;
  - ротация (глубина хранения — 10 копий);
  - атомарная замена и «страховочная» копия перед восстановлением.
- **Диагностика:**
  - `cProfile` — профиль функций по времени;
  - `tracemalloc` — снимки памяти;
  - `py-spy` — Flame Graph без изменения кода.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Sn0w-t3a/Educational-practice-2026.git
cd Educational-practice-2026
```

### 2. Виртуальное окружение (рекомендуется)

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Содержимое `requirements.txt`:

```
pytest>=8.0
pytest-cov>=5.0
py-spy>=0.3
```

> Опционально для расширенной диагностики: `pip install yappi line_profiler memory_profiler scalene`.

## Запуск

### Основная программа

```bash
python main.py
```

Далее следуйте меню:

```
===== МЕНЮ =====
 1. Сложение A + B
 2. Вычитание A - B
 ...
 r. Сбросить A и B
 3. Выход
================
```

### Запуск тестов

```bash
pytest test_functions.py -v
```

С покрытием:

```bash
pytest test_functions.py --cov=functions --cov-report=term-missing
```

### Резервное копирование и восстановление шаблонов

```bash
# Создать резервную копию
python -m template_backup --backup

# Список доступных копий
python -m template_backup --list

# Восстановить из последней копии
python -m template_backup --restore

# Восстановить из конкретного архива
python -m template_backup --restore --archive backups/templates_2026-10-28_10-15-00.zip

# Восстановить с принудительным продолжением при несовпадении хэша
python -m template_backup --restore --force

# Восстановить только валидные шаблоны
python -m template_backup --restore --skip-invalid
```

### Диагностика

```bash
# cProfile + tracemalloc
python diagnostics.py --cprofile --memory

# py-spy Flame Graph
python diagnostics.py --pyspy --script main.py
```

## Соответствие регламенту технического обслуживания

- **Периодичность планового бэкапа** — ежедневно в нерабочее время (по cron / «Планировщику задач»), плюс автоматически перед каждым восстановлением.
- **Глубина хранения** — 10 последних копий (`MAX_COPIES = 10`).
- **Контроль целостности** — SHA-256 архива в `manifest.json` + SHA-256 каждого шаблона внутри архива.
- **Протоколирование** — все операции фиксируются в `logs/app.log`.
- **Тестирование восстановления** — не реже раза в квартал в тестовый каталог `templates_test/`.
